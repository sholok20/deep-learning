# Deep Learning Assignments 

This repository contains my Deep Learning course assignments, covering fundamental and advanced concepts including MLPs, CNNs, optimization, transfer learning, RNNs, LSTMs, and Restricted Boltzmann Machines (RBMs).

The assignments were implemented using Python and Jupyter/Google Colab, with experiments, model training, evaluation, and visualization included in the notebooks.


#  MLP, CNN & Optimization

This assignment focuses on the fundamentals of neural networks and deep learning optimization.

Topics covered:

Multilayer Perceptron (MLP)
Convolutional Neural Networks (CNN)
Neural network architecture
Forward propagation
Backpropagation
Activation functions
Loss functions
Optimization algorithms
Model training and evaluation
Performance visualization
